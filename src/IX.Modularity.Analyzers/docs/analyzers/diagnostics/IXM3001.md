# IXM3001: Service operation must return FluentResults

Externally visible service operations must return `FluentResults.Result` or `FluentResults.Result<T>`, directly or inside `Task` or `ValueTask`. This makes expected, caller-actionable outcomes explicit without using raw values, Boolean flags, nullable sentinels, or ordinary exceptions as a business-outcome channel.

The rule reports the interface-owned contract once and does not duplicate that report on its implementation. Constructors, accessors, operators, private helpers, generated code, and ordinary non-service implementations are excluded.
