# IXM3003: Broad exception catch must rethrow

An untyped catch or `catch (Exception)` may add safe context or perform cleanup only when every reachable path ends with bare `throw;`. A bare rethrow preserves the original exception and stack.

The rule rejects fall-through, return statements, failed-result conversion, replacement exceptions, `throw exception;`, and conditional paths that can swallow a broad catch. Specific exception catches remain subject to review: translate only a documented, fully understood expected outcome to a coded result, and always propagate cancellation.
