# IXM1005: Service members require complete XML documentation

Externally visible members of service interfaces and externally visible members directly declared by non-interface service types must document their summary, generic type parameters, parameters, return value, and property value where each applies. External visibility includes `public`, `protected`, and `protected internal` members. This includes inherited service interfaces.
